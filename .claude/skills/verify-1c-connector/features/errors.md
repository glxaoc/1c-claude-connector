# Ошибки 1С и сети понятным текстом

Пользователь не технический: на любую ошибку он должен получить, что исправить, по-русски,
без стека и кодов Node.

| Ситуация | Ответ коннектора (ключевые слова) | Где проверено |
|---|---|---|
| 401 | «отклонила логин или пароль (401)», совет про латинский логин | smoke 5, suite |
| 403 | «нет прав на этот объект (403)» + текст 1С | smoke 5 |
| 404 объекта | «Объект не найден (404)», совет `list_objects` | smoke 5, suite |
| 404 базы | «По этому адресу нет OData», «имя базы» | suite |
| 400 | «1С не поняла запрос (400)» + текст 1С, совет `describe_object` | smoke 5, suite |
| 500 | «Ошибка на стороне 1С (500)» + текст 1С | smoke 5, suite |
| 502/503/504 | «Веб-сервер перед 1С ответил 502» | smoke 5, suite |
| HTML вместо JSON | «страницу вместо данных», окончание адреса | smoke 5 |
| Порт закрыт | «отказал в соединении» | smoke 5 |
| Домен не найден | «не найден» | suite (DNS-запрос `.invalid`) |
| Пустой адрес | «Не указан адрес OData» | smoke 5, suite |
| SSH: пароль, ключ, белый список | подсказки про методы входа и белый список | suite |

Новая ветка в `odataGet` или `netError`: добавить строку сюда и случай в smoke (раздел 5).
