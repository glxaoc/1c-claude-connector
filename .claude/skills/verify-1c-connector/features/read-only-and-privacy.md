# Только чтение и данные клиента

Обещание в README и манифесте: «коннектор отправляет в 1С лишь запросы на получение данных»,
«пароли в защищённом хранилище и в чат не попадают».

Что держит обещание и где проверяется:

| Что | Где в коде | Проверка |
|---|---|---|
| Все HTTP-запросы GET | `httpGetOnce`, `method: "GET"` | smoke 2 (код) и 6 (заглушка видит только GET) |
| Имя объекта не выходит за OData | `safePath` (запрет `?`, `#`, `://`, `..`, `\`) | smoke 4, suite «попытка выйти за OData» |
| Нет инструментов записи | `registerTool`, `readOnlyHint: true` | smoke 3 |
| Пароль не в журнале и ответах | `log(...)` пишет путь без параметров | smoke 6 |
| Данные строк и фильтры не в журнале | `log("GET", p, status, ms, bytes)` | smoke 6 |
| Пароли в хранилище ОС | `manifest.json` `sensitive: true` | smoke 1 |
| Сообщение автору без пароля и адреса | `contact_author` | smoke 4, suite |
| Справка про 152-ФЗ при полях ПДн | `piiHint` | smoke 3, suite |

Осторожно: `log("redirect", …)` пишет полный адрес редиректа вместе с параметрами запроса
(`$filter` может содержать имя клиента). Smoke это не ловит, редирект в нём не вызывается.
