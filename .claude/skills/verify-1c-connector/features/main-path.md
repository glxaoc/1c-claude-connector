# Главный путь: вопрос о данных 1С

Кто: владелец или сотрудник компании, не технический специалист, в Claude Desktop.

1. Устанавливает `.mcpb`, заполняет адрес OData, логин и пароль 1С (только чтение).
2. Пишет «проверь связь с 1С»: `check_connection` по шагам показывает адрес, вход, число объектов,
   примеры вопросов. Покрыто smoke (раздел 3) и `tests/suite.mjs`.
3. Спрашивает «покажи 5 последних реализаций с контрагентом»: Claude зовёт `list_objects` с
   `contains`, `describe_object`, `query` с `select=…,Контрагент/Description`. Коннектор сам
   подставляет `$expand`. Покрыто smoke (раздел 3).
4. «Какие остатки на складах»: `query` по `AccumulationRegister_…/Balance()` с названиями товара
   и склада. Покрыто smoke.
5. «Сколько документов»: `count`. Покрыто smoke.
6. Несколько баз (до трёх, параметр `base`): только `tests/suite.mjs`.
7. Через сервер-посредник по SSH (1С за белым списком IP): только `tests/suite.mjs`.
